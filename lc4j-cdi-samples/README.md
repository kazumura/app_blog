LangChain4j-CDIのサンプルプログラム

# 構成
 * chat01-lc4j : LangChain4jの例
 * chat02-aisv : RegisterAIServiceの例
 * chat03-record : レコード、テンプレートの例 
 * chat04-guard : ガードレールの例 
 * chat05-tool : ツールの例 
 * chat06-otel : OpenTelemetryの例 
 * chat07-ft : MicroProfile FaultToleranceの例
 * chat08-rag : RAGの例

# 使用方法

各ディレクトリ下で、

```
 mvn clean compile exec:java
```
または、

```
 mvn clean compile exec:java -Dexec.args={コマンドライン引数}
```
